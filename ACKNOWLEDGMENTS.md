# Acknowledgments

Telemetry exists because many people made their work, knowledge, tools, and
services available to others. Thank you to everyone who contributed directly or
indirectly, including maintainers, reviewers, documentarians, issue reporters,
and community members whose names may not appear individually below.

## Inspiration and financial data

- **The `srichs/tsp-analytics` contributors** for their MIT-licensed work. Their
  approach helped validate Telemetry's request and caching strategy for official
  TSP closing-price data.
- **The U.S. Federal Retirement Thrift Investment Board and the TSP.gov team**
  for publishing official Thrift Savings Plan fund-price history.
- **Yahoo Finance** for making market information available, and **Ran Aroussi
  and the yfinance contributors** for the open-source Python interface used to
  retrieve historical market closes.

## Application foundations

- **The Python Software Foundation and Python community** for the language and
  standard library used throughout Telemetry.
- **The SQLite developers** for the dependable embedded database that stores
  Telemetry's local data.
- **The Qt Company, the Qt Project, and the Qt for Python/PySide contributors**
  for the cross-platform application and QML interface framework.
- **Jason R. Coombs and the keyring contributors** for secure integration with
  Windows Credential Manager.
- **The Python Cryptographic Authority and cryptography contributors** for the
  cryptographic primitives used by encrypted backups.

## Building and distribution

- **Hartmut Goebel, Giovanni Bajo, David Vierra, David Cortesi, Martin Zibricky,
  and all PyInstaller contributors** for the tooling used to create the Windows
  executable.
- **The Pillow contributors** for image tooling used during Windows packaging.
- **Jordan Russell, Martijn Laan, and the Inno Setup contributors** for the
  Windows installer system.
- **Git and GitHub contributors**, including the GitHub Actions teams, for source
  control, collaboration, and automated testing infrastructure.
- **Microsoft and the Windows platform teams** for Windows, Credential Manager,
  EFS, and the APIs on which the desktop application relies.

## Services and development assistance

- **Google and the Gmail teams** for the SMTP and App Password facilities used

- **OpenAI and Codex** for AI-assisted development, review, testing, security

  and responsibility for Telemetry remain with its maintainer.
- **Family members, testers, and future contributors** who provide ideas,
  feedback, bug reports, and encouragement.
